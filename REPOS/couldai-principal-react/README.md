# SmartGov AI
Public Service Failure Early Warning System

## Overview
An AI + IoT based Public Service Failure Early Warning System that predicts failures before they occur in Electricity, Water Supply, and Waste Management departments. The system monitors live sensor data, analyzes AI predictions, detects risks, notifies departments, and provides early warnings.

## Features
- **Super Admin Dashboard**: A Smart City Command Center showing overall risk across departments.
- **Risk Metrics**: High-level tracking of Electricity, Water, and Waste risks, plus AI prediction accuracy.
- **Modern UI**: Dark theme, glassmorphism-inspired components, responsive layout, and interactive charts (simulated via UI cards).
- **Responsive Navigation**: Adaptive sidebar for desktop/tablet and bottom navigation/drawer for mobile.

## Tech Stack
- **Frontend**: Flutter (Cross-platform: Web, Desktop, Mobile)

## Setup and Run
1. Ensure Flutter is installed.
2. Run `flutter pub get` to install dependencies.
3. Run `flutter run` to start the app.
